HOTEL NORLING WEBSITE
=====================

Pages
  index.html     Home
  rooms.html     Rooms (Standard & Deluxe)
  dining.html    Food & Rooftop
  explore.html   Samagaun - things to do
  gallery.html   Photo gallery with filters + full-screen viewer
  about.html     Our Story / meet your host
  contact.html   Contact, booking form, map, FAQ
  404.html       "Page not found" page

Shared files
  css/style.css  All styling (colours are at the top under :root)
  js/main.js     Menu, WhatsApp booking, gallery, photo viewer
  images/        Optimised WebP photos in 3 sizes each (phones load the small ones)

To preview: double-click index.html.

To put it online: upload the whole "website" folder as-is to any static host
(Netlify Drop, GitHub Pages, Cloudflare Pages, or your web hosting's public_html).

Before going live: if the domain is not hotelnorling.com, replace that address in
sitemap.xml, robots.txt and the <link rel="canonical"> / og: tags at the top of each page.
